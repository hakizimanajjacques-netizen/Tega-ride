# TegaRide — Move Rwanda. Move Easy.

Ride-hailing platform (Moto + Car) for Rwanda, launching in Kigali.

```
TegaRide/
├── frontend/   React + Vite + TS + Tailwind  → Vercel
├── backend/    Express + TS + Prisma         → Render
└── (database)  Supabase PostgreSQL
```

## Run the backend locally (current state)

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

Check: http://localhost:5000/api/health

The full README (deployment, API docs, etc.) is written in the final steps.
